# 📘 Assignment: Hangman Game

## 🎯 Objetivo

Build a classic word-guessing game in Python using strings, loops, conditionals, and user input. The goal is to practice logic, validation, and interactive programming while creating a simple terminal game.

## 📝 Tarefas

### 🛠️ Build the Core Gameplay

#### Descrição
Create a terminal-based game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requisitos
O programa concluído deve:

- choose a secret word from a predefined list of words
- display the hidden word using underscores and correctly guessed letters
- accept one letter at a time from the user and validate the input
- track the number of incorrect guesses and remaining attempts
- end the game when the player wins or loses and show the final result

### 🛠️ Improve the Player Experience

#### Descrição
Add a few simple improvements to make the game clearer, more enjoyable, and easier to play.

#### Requisitos
O programa concluído deve:

- show a clear message after each guess
- prevent repeated guesses from reducing the player's remaining attempts unnecessarily
- display the final word and whether the player won or lost
- keep the code organized with clear functions or logical sections
